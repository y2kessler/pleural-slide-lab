iPhone-first local prototype — choose a video from Photos/Files, pause on a clear frame, capture it, then draw the pleural ROI.
1) Choose from Photo Library or Files. 2) Play/scrub to a clear pleural frame and pause. 3) Tap Capture Frame for ROI. 4) Drag a narrow box across the pleural line. 5) Analyze. Include pleural irregularities/speckle while minimizing ribs and deeper artifact.

Consensus pleural displacement
Vertical markers = detected phase reversals. Displacement is relative and in screen pixels; no physical calibration is applied in v0.3.
Method: multiple textured patches are selected across the pleural ROI. Each patch is matched horizontally frame-to-frame by normalized intensity error; median patch motion forms the consensus. A superficial reference strip estimates global/probe motion and is subtracted. The trace is smoothed, then prominent direction reversals define phases. This prototype is for method development/research, not clinical decision-making.
